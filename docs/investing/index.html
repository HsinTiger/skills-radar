財經投資研究專區

投資專區只建立可追溯、可重算、可被反駁的研究流程；不連帳戶、不下單、不把模型分數變成方向指令。

市場／總經資料、財報與盈餘品質、估值、產業鏈論點、風險與回測方法。

排除：自動下單、實盤交易、券商／錢包／私鑰／credential 操作，以及無證據的獲利承諾。
