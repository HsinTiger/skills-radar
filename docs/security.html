這份掃描不是什麼

它不是門禁，也不可宣稱為完整防護。定位是「決定哪些樣本要人看 + 量化生態風險」。

  • 規則與 LLM 必須並用。規則式偵測抓的是語法樣態，LLM 自標抓的是語意操控， 兩者的交集很小。單靠任一種都會漏。
  • 規則有明確誤判。「不要叫使用者把 API key 貼進 MCP client」這種正確的安全建議， 會被規則標成「隱瞞使用者」。命中數要當成待審清單，不是罪證。
  • 隱藏字元多半無害。實測絕大多數是零寬空格與 BOM（複製貼上與 emoji 造成）， 沒有觀察到雙向覆寫或標籤字元，也就是沒有刻意的 Unicode 隱寫。
