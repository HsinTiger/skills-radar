# EDA／數位 IC 設計專區 — 2026-07-28

> 狀態：`READY_FOR_OWNER_REVIEW`；排程來源：`manual_recovery`。
> public source review != VCS/Verdi/DC/PrimeTime/formal runtime proof

對 WiFi baseband ASIC，先自動化意圖與證據，再自動化 RTL mutation。最有價值的不是把第三方 skill 整包裝進公司環境，而是抽出可審查契約，由 OA 產 deterministic bundle、NX 跑真實 EDA、證據回流後才升級 claim。

## 多週期 AI 觀點

### 日尺度 — 2026-07-27

**今天沒有足夠的新資料，最好的判斷是暫時不下結論**

今天沒有新的電子設計自動化或數位晶片設計材料，因此不調整無線網路基頻設計的採用清單。

日尺度只決定今天是否有新的 source/review/evidence 需要處理；不因單日件數改寫設計方法。

反方觀點：公開 skill 供給很可能低估公司內數位 IC 實務；secondary taxonomy 目前為 BLOCKED，因此候選數與關鍵字命中不能替代人工審查或 NX runtime evidence。

## ASIC automation／研究路線

### 1. 設計意圖編譯器

design intent、cycle contract、fixed-point/interface/reset invariants 與 acceptance boundary。

候選：digital-front-end-skill、rtl-specification-consistency-checker

證據：spec/cycle table readback；尚不是 RTL 功能 PASS。

### 2. Verification contract factory

stimulus space、bounded wait、scoreboard、reset/backpressure、coverage exit gate。

候選：尚無

證據：VCS compile/sim、seed manifest、mismatch log 與 coverage readback。

### 3. Spec-linked property factory

每條 candidate property 對應 requirement，分開 assume/assert/cover。

候選：rtl-property-inference、rtl-p5s-sva-check、assertion-design

證據：正式 proof result、vacuity 與 counterexample review。

### 4. VCS／Verdi 證據萃取器

可重跑的 FSDB event/coverage query 與 bounded JSON evidence。

候選：x-npi、write-sim-testbench

證據：同一 clock edge sampling、API readback、compile/sim status 與 denominator。

### 5. Synthesis／STA claim governor

RTL/filelist/tool/library/corner manifest；lint、DC、LEC、PrimeTime、power claims 分層。

候選：assess-synthesis-and-inference、logic-synthesis、rtl-repair

證據：真實 DC／LEC／PrimeTime／power report readback；各 gate 不互相替代。

### 6. Evidence-backed learning loop

只回流獲准的 manifest、claim、失敗模式與通用方法，形成跨 block 可複用資產。

候選：尚無

證據：另一個 agent 可由 checkpoint 重現 exact next action，不需 owner 重講上下文。
